# Etapa 2 - Instalar Dependências
 
Instale as bibliotecas necessárias:
 
```bash
npm install express bcryptjs jsonwebtoken dotenv mysql2 cors
```
 
Instale o Nodemon:
 
```bash
npm install nodemon --save-dev
```
 
## Para que serve cada biblioteca?
 
| Biblioteca | Função |
|------------|---------|
| express | Criação do servidor |
| bcryptjs | Criptografia de senhas |
| jsonwebtoken | Criação de tokens JWT |
| dotenv | Leitura do arquivo .env |
| mysql2 | Conexão com MySQL |
| cors | Liberação de acesso da API |
| nodemon | Reinicia servidor automaticamente |
